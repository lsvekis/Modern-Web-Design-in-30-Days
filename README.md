# Modern Web Design in 30 Days

## Learn HTML, CSS & JavaScript Through Hands-On Projects and Vibe Learning

View https://lsvekis.github.io/Modern-Web-Design-in-30-Days/

**Modern Web Design in 30 Days** is a practical, beginner-friendly journey through the foundations of modern web design and front-end development.

Rather than treating HTML, CSS, and JavaScript as separate subjects to memorize, the book focuses on learning by building, experimenting, debugging, and improving real web pages.

Over 30 days, readers progress from understanding how websites work to creating, improving, and publishing a complete interactive website.

## What You'll Learn

Throughout the 30-day journey, you'll work with:

- HTML page structure and semantic elements
- Text, links, images, lists, and navigation
- CSS selectors, properties, and the box model
- Flexbox and CSS Grid
- Responsive and mobile-first web design
- Typography, color, spacing, buttons, and forms
- JavaScript fundamentals
- Events and user interaction
- Conditional logic and functions
- Arrays, loops, and objects
- DOM manipulation and dynamic content
- Debugging and browser developer tools
- Refactoring and code quality
- Accessibility and inclusive web design
- Performance and web-development best practices
- Deployment and publishing
- Portfolio development and continued learning

## The 30-Day Learning Journey

The book is structured as a progressive learning experience. Each day introduces new concepts while building on what came before.

The early lessons establish HTML and CSS fundamentals. The middle of the book introduces responsive layouts and JavaScript. Later lessons bring these technologies together through dynamic content and project development.

The final portion focuses on the skills that turn coding knowledge into practical web-development ability: debugging, refactoring, accessibility, performance, deployment, and portfolio development.

## Learning by Building

The examples in this repository accompany the lessons and exercises in the book.

The goal is not simply to read code. Readers are encouraged to:

1. Build the example.
2. Run it in the browser.
3. Change something.
4. Predict what will happen.
5. Test the change.
6. Debug unexpected results.
7. Improve the code.

This experiment-driven approach is a central part of the book's learning process.

## Vibe Learning

Modern Web Design in 30 Days incorporates **Vibe Learning** — using curiosity, experimentation, reflection, and AI-assisted learning to develop understanding rather than simply copying solutions.

AI can be used as a learning partner to:

- Explain unfamiliar code
- Ask debugging questions
- Suggest experiments
- Review code structure
- Explore alternative approaches
- Reinforce concepts
- Help identify areas for improvement

The objective is always to understand what the code does and why it works.

The `source-snippets` directory contains the individual HTML, CSS, and JavaScript examples used throughout the book.

Use:

`source-snippets/index.html`

## Running the Examples

Most examples require no installation or build process.

Clone or download the repository and open the main `index.html` file in a modern web browser.

You can also open individual examples directly from the `working-examples` directory.

A code editor such as Visual Studio Code can be useful when experimenting with the examples.

## Who This Book Is For

This book is designed for:

- Complete beginners learning web development
- Students learning HTML, CSS, and JavaScript
- Self-taught developers strengthening their fundamentals
- Designers who want to understand front-end code
- Anyone who learns best by building and experimenting

No previous programming experience is required.

## By the End of the Book

After completing the 30-day journey, readers will have experience creating structured web pages, styling responsive layouts, adding JavaScript interactivity, working with dynamic content, debugging problems, improving accessibility and performance, and publishing a website online.

More importantly, the goal is to develop a repeatable process for learning web technologies independently:

**Build → Experiment → Debug → Improve → Reflect → Build Again**
